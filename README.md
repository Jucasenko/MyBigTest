# Итоговая аттестация по программированию

**Автор:** Твое Имя и Фамилия

**Проект:** Random Quote Generator  

## Описание
Приложение с графическим интерфейсом (GUI) на Python для генерации случайных цитат и ведения истории просмотров.

## Функции программы:
1. **Генерация:** По кнопке выбирается случайная цитата из базы.
2. **История:** Список всех просмотренных цитат отображается на экране.
3. **Сохранение:** История автоматически пишется в JSON-файл на диске.
4. **Фильтры:** Поиск цитат в истории по авторам и темам.
5. **Валидация:** Проверка пустых полей при добавлении новых цитат.
