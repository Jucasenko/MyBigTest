# Итоговая аттестация: Random Task Generator

**Автор:** Устинов Тимофей  
**Класс:** 9 класс  
**Проект:** Графическое приложение «Генератор случайных задач»

## Описание проекта
Программа на базе библиотеки `tkinter` выбирает случайные задачи из встроенного списка и ведёт историю просмотров сессии. Логика сохранения данных полностью изолирована от GUI и вынесена в класс `TaskDataManager`.

## Реализованные требования:
1. **Генерация:** Использование модуля `random` для выбора случайных активностей.
2. **Фильтрация:** Сортировка истории выполненных задач по типам (учёба, спорт, работа).
3. **Хранилище данных:** Автоматическая сериализация/десериализация истории в JSON-файл с точной обработкой исключений (`FileNotFoundError`, `JSONDecodeError`).
4. **Валидация:** Проверка на пустые строки при создании задач.

## Требования к запуску
* Среда выполнения: Python 3.x
* Зависимости: стандартные встроенные библиотеки (`tkinter`, `json`, `random`)

## Запуск приложения
Выполните команду в терминале:
```bash
python main.py
```

## Тестирование (Примеры использования)
1. Нажмите «Сгенерировать задачу» — вверху экрана появится случайное задание.
2. В блоке добавления оставьте поля пустыми и нажмите «Добавить в пул задач» — сработает триггер валидации.
3. Отфильтруйте историю, выбрав категорию «Спорт» и нажав «Применить фильтр».
