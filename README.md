# Итоговая аттестация по программированию

**Автор:** Устинов Тимофей  
**Класс:** 9 класс  
**Проект:** Random Quote Generator Pro

## Описание
Приложение с графическим интерфейсом (GUI) на Python для генерации случайных цитат и ведения истории просмотров.

## Инструкция по запуску
1. Установите Python версии 3.x (библиотека `tkinter` является встроенной и не требует отдельной установки).
2. Скачайте файл `main.py`.
3. Запустите проект через терминал/консоль командой:
   ```bash
   python main.py
   ```

## Примеры использования (Тесты)
1. **Тест генерации:** Нажмите «Сгенерировать цитату» — в центре появится случайный текст.
2. **Тест валидации:** Оставьте поля добавления пустыми и нажмите «Сохранить в базу» — программа выдаст предупреждение.
3. **Тест сохранения:** Закройте приложение, откройте снова — старая история загрузится из файла `history.json`.
